# Project Quality Gates — {{project_name}}

> Project gates are **additive**. Base technology gates (e.g. `SFG*`, `DPPG*`)
> and framework gates (`QG*`) always load and are never replaced by this file.
> Project gates use the `PRG<phase>.<n>` namespace so they never collide with
> framework or technology gate IDs.

## Gate ID convention

`PRG<phase>.<n>` — e.g. `PRG5.1` is the first project gate for Phase 5.

## Gates

### PRG2.1 — Specs completeness

- **Phase**: 2
- **Requirement**: every functional requirement has testable acceptance criteria.
- **Evidence**: link to the specs artifact section.

### PRG5.1 — Project review sign-off

- **Phase**: 5
- **Requirement**: the project-specific review checklist is completed before
  verification.
- **Evidence**: checklist link.
