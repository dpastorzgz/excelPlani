# Release Notes — CR-004: Secciones colapsables en el Gantt

**Fecha**: 2026-10-26

## Nuevas funcionalidades

- **Detección automática de secciones**: filas del Excel sin asignado, duración ni fechas se identifican como secciones agrupadores.
- **Cabeceras de sección en el Gantt**: cada sección aparece como una fila sombreada en el panel izquierdo y en el SVG.
- **Colapsar/expandir secciones**: botón con chevron (▶/▼) por sección; al colapsar se muestra barra resumen (gris/verde); al expandir se muestran las tareas individuales.
- **KPIs inalterados**: el estado de colapso no afecta métricas.
- **Accesibilidad**: `aria-expanded`, `aria-controls`, operable por teclado.
